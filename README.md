# KIDER — Kids Daycare & Childcare Center

> **Nurturing Young Minds, Every Day.**

KIDER is a premium, framework-free HTML/CSS/vanilla JS template for kids daycare and childcare centers. It features a playful, colorful design system built around a green, orange, and yellow palette with rounded, child-friendly aesthetics.

## Live Pages

| Page | Description |
|------|-------------|
| `index.html` | Home — hero, programs preview, about section, testimonials, CTA |
| `about.html` | About — center story, core values, staff team |
| `programs.html` | Programs — 6 detailed program cards with age groups, activities, and enrollment CTAs |
| `contact.html` | Contact — enrollment inquiry form with validation, hours, location, map |

## Design System

- **Colors**: Green `#16A34A` + Orange `#F97316` + Yellow `#FACC15` + White
- **Typography**: Baloo 2 (headings) + Quicksand (body) from Google Fonts
- **Style**: Playful, rounded, colorful, child-friendly
- **Responsive**: Desktop, tablet (980px), mobile (720px)

## Quick Start

Open `index.html` in any modern browser. No build tools required.

```bash
# Or serve locally
npx serve .
```

## Features

- Full design system with CSS custom properties (500+ lines)
- Scroll-triggered reveal animations via IntersectionObserver
- Mobile hamburger navigation with smooth transitions
- Enrollment form with client-side validation and success/error states
- Animated counters for statistics
- Staggered card reveals
- Prefers-reduced-motion support
- Print-ready styles
